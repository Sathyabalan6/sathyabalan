# Sathya Balan K — Personal Website & Portfolio

A personal website built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, featuring tactical dark design patterns adapted from [Ashutoshx7/VengeanceUI](https://github.com/Ashutoshx7/VengeanceUI).

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm run start
```

Runs on [http://localhost:3000](http://localhost:3000).

## 🚀 Easy Deployment

### Deploy on Vercel (Recommended)
Push this repository to GitHub and import it into [Vercel](https://vercel.com) — zero configuration required!

### Update Portfolio Data
All personal details, projects, stats, and links are dynamically loaded from [`portfolio-data.json`](./portfolio-data.json). Updating that file instantly updates the entire website.
